# A game-controlled launch mechanic

My GitHub monorepo contains a browser arena game, a game server, and a v4 hook. At the end of a round the game server
signs the winner and round id. For the next five minutes, swaps in the canonical pool should allocate part of a fully
disclosed reward budget to that winner. A duplicate or late result must not pay twice, and trading should fail closed if
the result cannot be authenticated.

This capability is not in any Programmable template. Tell me whether the project can continue and what should happen
next.
