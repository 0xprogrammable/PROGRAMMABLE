# V4 token

V4 is the ecosystem token named by Programmable's public revenue policy. Use the Ethereum contract address rather than the name or ticker to identify it.

| Field             | Value                                              |
| ----------------- | -------------------------------------------------- |
| Network           | Ethereum Mainnet                                   |
| Contract          | `0x7987f03462200b3D8A072E02C89A8A41dCB124EE`       |
| Revenue purchases | Held by the protocol revenue wallet when processed |
| Burn              | No burn is described by the public revenue policy  |

The published allocation assigns 80% of attributable net protocol revenue to V4 purchases and 20% to the treasury. The production processor and its activation record determine which allocation executes for a given cycle, so a policy page is not a transaction receipt.

Holding V4 does not represent equity in Programmable and does not create a claim on protocol revenue. Purchases do not guarantee price, liquidity or returns, and a new revenue source is not processed until its source profile is verified and activated.

The official token page on [Dexscreener](https://dexscreener.com/robinhood/0x3df16f271060e4941c0386047def159f42e629dc0455db623c5b363eeacbcc1d) can be useful for price and liquidity context, while the contract address remains the identity.
