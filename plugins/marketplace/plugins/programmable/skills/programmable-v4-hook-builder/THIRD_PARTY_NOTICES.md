# Third-party source boundaries

This skill is MIT licensed. It cites protocol specifications, source repositories and security guidance to document the
basis for its checks. Those references do not relicense third-party material.

The package does not redistribute Uniswap or OpenZeppelin contract source. It records repository identities, commits,
package integrities, licenses and short factual interoperability rules. Builders must check the license of every file
they import or adapt.

The Uniswap Foundation security framework is cited as a review reference. Its repository did not publish a license at
the pinned revision recorded in `references/upstream-sources.json`. The risk checks in this skill are an independent
implementation for Programmable intake; no Foundation prose or code is sublicensed here. Treat the cited repository as
reference-only unless its owner grants a license.

Educational, test-only, unlicensed, obsolete and under-construction repositories are classified explicitly in
`references/upstream-sources.json`. None is a production baseline.
